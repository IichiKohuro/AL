Популяция

травоядные всеядные хищники растения

Цвет тела — вид или родство (переключается вверху), обводка — рацион: зелёная — травоядное, жёлтая — всеядное, красная — хищник. Красная дуга — укус.

Вид отделяется, когда группа из нескольких особей заметно уходит от среднего облика своего вида: по рациону, размеру, скорости, зрению, цвету. Клик по виду подсвечивает его в мире.
